CAMO//FORGE PWA – Hosting-Paket

Enthalten: index.html, manifest.webmanifest, sw.js, App-Icons.

Eine installierbare PWA benötigt eine HTTPS-Adresse. Lade den INHALT dieses Ordners z. B. auf GitHub Pages hoch. Danach auf dem iPhone in Safari die veröffentlichte HTTPS-Seite öffnen -> Teilen -> „Zum Home-Bildschirm“.

Offline-Nutzung wird nach dem ersten Laden unterstützt. Fortschritt bleibt im lokalen Browser gespeichert und synchronisiert nicht automatisch zwischen Geräten.
